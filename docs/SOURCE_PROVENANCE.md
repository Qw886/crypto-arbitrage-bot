# 源码来源与核查范围

本副本基于作者主导、AI 辅助开发的 crypto-arbitrage-bot 本地工作区提取，
不根据“AI 编写”推断代码必然原创，也不将代码来源核查写成法律保证。

| 范围 | 本次处理 |
| --- | --- |
| src/crypto_arbitrage_bot | 保留产品源文件，未修改金融公式、策略、风控或订单逻辑 |
| tests | 保留全部正式测试；候选中的 13 个文件仅作导入、显式 fixture 导出及等价写法整理 |
| work | 只保留产品/测试依赖的 19 个原辅助文件，不包含下载的第三方机器人或研究样本 |
| docs/*.toml | 保留测试所需既有配置；历史开关、时间窗口不是当前运行许可 |
| 第三方依赖 | 由包管理器安装，来源和版本见 DEPENDENCY_INVENTORY.md；不分发虚拟环境 |

原始文件和候选差异有独立审查记录。本次没有删除已有署名；
选定源码范围内没有检索到 Hummingbot 引用或版权/许可证头，不能据此推断没有任何外部来源。

与本地 Hummingbot 的进一步比较覆盖 1,653 个可解析 Python 文件、8,097 个函数；
候选覆盖 321 个 Python 文件、2,127 个函数。按不少于 80 个 AST 节点、忽略函数名与首段文档字符串
进行结构比较，没有完全一致的匹配。原有逐文件比较也未发现一致文件。
此方法不覆盖全面改名、改写、其他上游项目或未保存的开发历史，不能作为独创性证明。

Hummingbot 原型和保存的第三方策略样本中存在 Apache 2.0 许可证副本；
这些目录未进入本发布副本。如果以后引入相关代码，应连同来源和适用许可材料另行审查。
